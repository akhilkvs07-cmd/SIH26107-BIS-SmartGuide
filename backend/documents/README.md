# BIS Knowledge Documents

Place permitted BIS reference material here as `.txt`, `.md`, or `.json` files.

The local RAG engine automatically reads these files when the Flask server starts.
Use `/rag-rebuild` after adding or changing documents.

Important: only add material you are permitted to use. Keep official BIS source URLs and document titles in the content/metadata where possible. The prototype must not present local documents as an official BIS certification decision.
