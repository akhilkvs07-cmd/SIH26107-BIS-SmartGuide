# BIS SmartGuide React Frontend

React + Vite frontend for SIH 26107.

## Development

```bash
npm install
npm run dev
```

## Production

```bash
npm run build
npm run preview
```

Set `VITE_API_URL` to the deployed Node.js backend URL. If omitted, the app currently uses the existing BIS SmartGuide API URL.

## Main modules

- Overview / command center
- BIS standard recommendation
- Compliance assessment
- Document/photo analysis
- CM/L format validation
- Assessment history / compliance passport
- Source-grounded AI assistant
- Official BIS resources
